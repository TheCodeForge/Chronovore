# Chronovore
Miniature tabletop wargaming in the grim dark future. And past. And present. Time no longer has any meaning.

# Minis
Chonovore is currently designed to be played using your existing collection of wargaming figurines.

# Why play Chronovore over other rule sets?
Simple:
1. Free: Unlike some other studios' official published rules, Chronovore rules are, and will always be, 100% free to use.
2. Simplicity: With Chronovore, you need only the current effective revision of two things: the core rules, and your faction-specific rules and unit cards. No more juggling a physical book, errata notes, printed downloads, patch notes, the errata for the patch notes, and some random-ass edition of a magazine that gives the other guy's Snotling a 2+++ FNP.
3. Convenience: The Chronovore website includes tools for listbuilding and army management. No third-party tools are required.

And no more buying a physical book that becomes obsolete in three weeks anyways - Rule updates will always be reflected directly within the on-site tools and datasheets.
